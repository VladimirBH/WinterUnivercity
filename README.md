# Сквозь века — WinterUnivercity

Проект знакомит с историей Лазаревской церкви через её 3D-реконструкции.

| Папка | Содержимое |
| --- | --- |
| [`backend/`](backend/) | Python-сервер с описаниями памятников, маршрутами и изображениями. |
| [`frontend/`](frontend/) | Android-приложение на Jetpack Compose. |
| [`3dModeling/`](3dModeling/) | Реконструкции церкви, материалы и скрипт для Blender. |

Редактируемые сцены хранятся в формате `.blend`. Для версии 1461 года доступен экспорт `.obj` с файлом материалов `.mtl`. Для AR-версии реконструкции 1862 года доступен файл `.glb`.

## Запуск демо

1. Откройте `frontend/` в Android Studio и выберите JDK 21 для Gradle.
2. В панели **Gradle** выберите **Execute Gradle Task** и запустите `runBackend`. Для сервера нужен Python 3. Путь можно задать параметром `-PpythonExecutable=...`.
3. Оставьте сервер запущенным и нажмите **Run** для модуля **app** на Android Emulator.

Сервер слушает `127.0.0.1:8080` на компьютере. Debug-приложение обращается к нему через `10.0.2.2:8080`. Сервер также можно запустить командой `python main.py` из `backend/`. APK включает копию `catalog.json` для работы без запущенного сервера. Медиа на экранах заменены серыми полотнами, экран поиска и переключение эпох демонстрируют сценарий AR вручную.
